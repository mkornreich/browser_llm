Browser LLM

One tiny library that gets you a language model in the browser. It uses Chrome's built-in Gemini Nano (the Prompt API) when it is there — nothing to download — and falls back to downloading SmolLM2-360M via transformers.js when it is not. Same generate() either way. Everything runs on your device; no text ever leaves the page.

Use it in your own code

      
<script src="browser-llm.js"></script>
<script>
  const llm = BrowserLLM.create();
  const brain = await llm.loadGenerator();          // Nano, or SmolLM2 if no Nano
  const text = await brain.generate(
    [{ role: "user", content: 'What is "photosynthesis"?' }],
    { max_new_tokens: 72, temperature: 0.6 },
    partial => { /* live tokens */ });
</script>
